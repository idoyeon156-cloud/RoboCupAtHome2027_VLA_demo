# 베이스 뒷면에 맞춘 3030 수직 프로파일

사용자가 확인한 배치: 두 사각 베이스 기하학적 중심을 잇는 선의 중점에 좌우 위치를 맞춥니다. 프로파일 뒷면과 양쪽 베이스 뒷면이 같은 평면이며, 프로파일은 앞쪽으로 30mm 뻗습니다. 높이는 베이스 설치면부터 500mm입니다.

현재 베이스 STL 경계는 X=[-58.5,40]mm, Y=[-40,40]mm입니다. 양팔 베이스 원점의 Y는 ±87.5mm입니다. 따라서 프로파일 중심은 world 기준 [-43.5,0,250]mm, 단면은 30×30mm, 높이는 500mm입니다. 사각 베이스의 기하학적 중심과 base_link 좌표 원점은 앞뒤 방향으로 다릅니다. world 원점은 기존 base_link 원점 사이의 중점으로 유지합니다.

## 수정 위치

config/robot.yaml의 attachments → rear_profile_3030:

```yaml
name: rear_profile_3030
parent: world
xyz: [-0.0435, 0.0, 0.25]
rpy: [0.0, 0.0, 0.0]
geometry:
  box: [0.03, 0.03, 0.50]
touch_links: []
```

위치·높이를 바꾸면 tools/prepare_model.py로 재생성합니다. 표시 URDF, 다면체 충돌 URDF, 거리 보호 구와 manifest가 같이 갱신됩니다. 두 시뮬레이터의 기존 실행 명령은 같습니다.

## 충돌 검사

- MoveIt: 고정 프로파일 외곽을 5mm 확장한 볼록 메시 1개를 추가합니다. 기존 양팔 72개와 합쳐 73개입니다. 프로파일과 양팔 모두의 충돌 검사가 켜져 있습니다. 체결 부품이나 움직이는 링크처럼 같은 팔 제외 목록에 합치지 않습니다.
- 조인트 거리: 기존 관절·그리퍼·마운트 보호 구와 프로파일 외접 구 사이의 표면 간격을 검사합니다. 프로파일은 최대 20mm 셀의 외접 구 + 5mm 여유로 덮습니다. 기존 양팔 사이 거리 검사도 유지합니다. 관절 보호 구가 팔 전체 표면을 덮는 방식은 아니므로 팔 중간 부위의 정밀한 간섭은 MoveIt 메시에서 확인합니다.
- 거리 미리보기에도 프로파일 보호 구와 가장 가까운 팔–프로파일 쌍을 표시합니다. 위험한 요청에서는 accepted 자세를 유지하고 ghost 자세를 표시합니다.
- 슬롯·홈을 생략한 30×30mm 꽉 찬 기둥으로 보수적으로 근사했습니다. 별도 체결 브래킷·볼트는 포함하지 않았습니다.

## 검증

영점에서 두 검사 모두 정상입니다. 왼팔과 오른팔 각각에 대해, 프로파일을 제외하면 통과하고 프로파일이 있으면 충돌로 검출하는 자세를 실제 MoveIt 서비스로 검사했습니다. 조인트 거리 방식에서도 동일한 근접 자세와 위험 자세 유지 동작을 확인합니다. 실제 드라이버 명령은 발행하지 않습니다.

HW/URDF/updated_gripper와 SW/updated_gripper, SW/cereal_pour에 같은 기둥 배치를 사용합니다. 왼팔 파지 자세와 기존 붓기 관절각은 변경하지 않았습니다.
