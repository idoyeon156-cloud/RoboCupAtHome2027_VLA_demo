# 교체한 그리퍼 + D405 마운트 v6

기존 updated_gripper를 갱신합니다. 별도 마운트 버전은 만들지 않습니다.

## 실행

```bash
bash run_distance_rviz.sh
bash run_meshes_rviz.sh
```

하나씩 실행하고 Ctrl+C로 종료합니다. 두 실행기 모두 같은 마운트 포함 모델을 사용합니다.

## 모델과 안전장치

- 양쪽 교체 그리퍼에 첨부 `PiPER_D405_mount_v6_assembly.stl`을 추가합니다. 출력 배치용 print STL은 사용하지 않습니다.
- 마운트는 gripper_base의 고정 visual/좌표 프레임입니다. 충돌 형상은 고정 조립체 gripper_flange에 합칩니다. 고정 조인트만 통과할 수 있으며 구동 관절을 넘겨 합치면 생성기가 거부합니다.
- MoveIt: 기존 그리퍼·플랜지 외곽에 마운트 외곽 4개 볼록 부품을 더합니다. 양팔 총 72개, 각 외곽의 5mm 여유를 유지합니다. 오목한 형상을 하나의 큰 볼록 껍질로 채우지 않고 여러 볼록 부품의 합으로 감쌉니다.
- 2026-11-13 소스 변경: 런처에서 기존 SRDF의 같은 팔 전체 제외를 제거합니다. 고정 조립체·단일 인접 관절 및 같은 그리퍼 두 손가락 맞닿음만 제외하며, 비인접 같은 팔 및 양팔 간 충돌은 검사합니다. 모델 원본 SRDF에는 과거 태그가 남아 있지만 계획/실행은 모두 `load_semantic`으로 변환한 값을 사용합니다. 새 범위의 빌드/동작 시험은 수행하지 않았습니다.
- 거리 안전장치: 기존 관절 7개 보호 구를 유지하고, 마운트의 전체 AABB를 20mm 이하 셀로 나눈 외접 구를 추가합니다. 각 구에는 5mm 여유를 더합니다. 표면 삼각형 내부까지 덮고, 손목 회전에 따라 FK로 이동합니다. 내부 빈 공간도 포함하는 보수적 근사입니다.
- D405 카메라 본체·USB 케이블은 첨부 ZIP에 별도 메시가 없어 이번 형상에 포함하지 않았습니다. 이번 반영 범위는 출력 마운트입니다.

## CAD 좌표 등록

CAD H 좌표는 mm 단위입니다. 닫힌 패드 TCP `(0,154.9,-2.4)`를 교체 그리퍼 base 기준 `(0,0,0.138)`m에 맞춥니다. 카메라는 볼록한 몸체 쪽인 link6의 -X 쪽입니다.

`G = (-H.z - 2.4, -H.x, H.y - 16.9)` mm.

config/robot.yaml: parent=gripper_base, xyz=[-0.0024,0,-0.0169], rpy=[pi/2,0,-pi/2], mesh scale=[0.001,0.001,0.001]. collision_parent=gripper_flange로 합칠 때 고정 플랜지 두께 4.5mm를 자동 적용합니다.

model/d405_mount_v6/에는 첨부 ZIP의 native/tcp/mesh 검사 기록과 원본 manifest를 보관합니다. 원본 기록은 실물 검증이 아닙니다.

## 재생성

config/robot.yaml과 소스 모델을 수정하고 tools/prepare_model.py를 실행합니다. 표시 URDF, MoveIt URDF, 보호 구 설정 및 manifest를 함께 갱신합니다. 생성 파일은 직접 수정하지 않습니다. 독립 HW 패키지는 SW/updated_gripper의 표시 URDF에서 패키지 이름만 바꾼 동일 형상입니다.

## 확인 범위 (2026-11-12)

메시 포함 관계, 마운트 좌표 등록, 손목 회전에 따른 보호 구 이동, 기존 관절 구가 놓치는 마운트 근접 자세의 차단을 검사합니다. 원본 표면의 J6 49자세 × 그리퍼 개방 3단계 간섭 검사도 포함합니다. MoveIt 서비스에서는 영점·바깥쪽 손목 회전의 정상 상태, 안쪽 회전 시 양쪽 마운트 외곽의 근접 충돌, 마운트 외곽에 상대 팔 형상을 겹친 충돌 상태를 검사합니다. 실물 끼움·카메라/케이블 포함 형상·물체를 잡은 상태는 별도 확인 대상입니다. 왼팔 자세와 붓기 시퀀스는 변경하지 않았습니다.
