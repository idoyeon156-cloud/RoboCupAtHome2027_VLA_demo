# 실물 전체 시퀀스 구동 결과와 남은 문제

2026-11-13, 한국 시간. 아래 결과는 사용자가 실물 구동 후 이 채팅에서 확인한 내용입니다.
이 기록을 작성하면서 로봇 실행·가드 리셋·속도 또는 제어 코드 변경을 수행하지 않았습니다.

## 사용자 확인 결과

- 그리퍼 명령을 제외한 팔 전용 모드에서 전체 시퀀스 완주를 확인했습니다.
- 전체 시퀀스에 덜덜거리는 움직임이 있습니다.
- 동작이 조금씩 끊깁니다.
- 속도가 느립니다.

전체 완주는 팔 경로의 실물 구동 확인입니다. 실제 물체 파지·붓기 성공, 그리퍼 정상 동작,
또는 충돌 방지·제동 성능의 검증 완료를 뜻하지 않습니다. 이전 접촉 사고 원인이 확정된 것도 아닙니다.

## 우선 해결할 항목: 그리퍼 미개방

- 일반 시퀀스는 알파 이후 `bowl_open`에서 개방 진행이 확인되지 않아 정지했습니다.
- 개방 목표는 30mm, 최종 가드 출력은 약 4.175mm까지 증가했으나 측정값은 0mm에 머물렀습니다.
- 3초간 진행 없음으로 실행기가 먼저 정지했고 목표 만료·J5 한계 오류는 뒤에 기록됐습니다.
- 사용자는 SDK 직접 개방 명령에서도 실제 움직임이 없다고 확인했습니다.
- 사용자가 제공한 SDK 출력은 갱신되는 타임스탬프, 200Hz, 개방 폭 -0.1mm,
  토크 0, `driver_enable_status: False`와 나머지 표시 오류 플래그 False였습니다.
- 따라서 그리퍼 피드백 수신은 확인됐지만, 테스트 당시 활성화가 성립하지 않았습니다.
  활성화 명령이 적용되지 않은 이유는 아직 미확정입니다.
- ROS 드라이버는 관절 모터 1~6의 활성화만 확인하며, 그리퍼 활성화 성공을 별도로 확인하지 않습니다.

다음 조사는 그리퍼의 실제 제어 모드·활성화 명령 전달·상태 응답을 우선 확인합니다.
힘 증가, 영점 재교정, 시간 제한 확대를 원인 확인 없이 해결책으로 적용하지 않습니다.

## 후속 개선 항목

떨림, 끊김, 느린 속도는 서로 관련될 수 있지만 원인은 미확정입니다.
향후 목표·피드백 변화, 경유점 정착 대기, 가드 대기, 제어기 명령 방식 및 속도 제한을
실행 기록과 대조해 구분합니다. 현재 기록만으로 특정 원인이나 수정 효과를 단정하지 않습니다.

현재 팔 전용 실행 방법은 `ARMS_ONLY_KO.md`를 참고합니다.

## 후속 사용자 확인 — 보간 개선 및 복귀 알파 감속 수정 이후

- 그리퍼 제외 모드를 유지한 실물 실행에서 **제로 자세까지 전체 완료**를 확인했습니다.
- 동작 속도가 빨라졌습니다.
- 동작 사이 끊김은 감소했으나 남아 있습니다.
- 덜덜거림도 여전히 남아 있습니다.

위 사항은 사용자가 새 시뮬 완료 후 실물을 실행해 전달한 결과입니다. 이번 기록 작업에서
추가 로봇 구동이나 코드·속도·허용폭 변경을 하지 않았습니다. 제로 복귀 성공은 이번 실행 결과이며,
이전 J5 한계 초과가 모든 조건에서 해결됐다는 검증이나 이전 접촉 사고 원인 확정을 뜻하지 않습니다.

다음 개선 대상은 반복 추종 대기의 발생 여부, 실제 경로 코너에서의 정지, 드라이버 MOVE J와
목표 전송 방식의 영향입니다. 새 실행 로그를 대조해 각각의 기여를 구분해야 하며,
기존 추종 허용폭을 늘리거나 충돌 가드를 해제하는 방식으로 증상을 숨기지 않습니다.

## GitHub 배포 시점 상태

사용자는 최신 개선 버전도 실물 성공으로 확인하고 해당 버전의 배포를 요청했습니다.
최신 실물 로그 `2026-11-13_19-17-35_51272`에도 `Finished; holding return_home`가 기록돼 있습니다.
후속 피드백 만료는 전체 완료 이후의 별도 상태이며 완주 기록과 구분합니다.
최신 시뮬 완료 기록은 현재 제어 소스 지문과 일치합니다. 배포에는 이 로컬 인증 파일을 포함하지 않습니다.
잔여 떨림의 원인은 조사 중이며, SDK 고정 목표와 ROS의 연속 중간 목표 처리 차이를 비교하는 단계입니다.
현재 배포는 시뮬 완료 후 실물 실행을 요구하며, 안정화 후 시뮬 없이 실행하는 방식으로 변경할 예정입니다.
